# draw-poker

Terminal draw poker implemented with Node.js and pnpm.

```sh
pnpm start
```

In an interactive terminal, use the left and right arrow keys to choose a card,
press Space to mark it for exchange, press `a` to exchange every card, and press
Enter to draw. Press `q` to quit.

When input is piped, the CLI keeps the text input mode: enter card numbers to
hold, separated by spaces or commas.
